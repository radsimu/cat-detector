# Test Frames

Place test images here for manual/integration testing.

Suggested file naming convention:

```
tp_cat_on_sofa_01.jpg       # True positive — cat(s) on sofa, no humans
tp_multiple_cats_01.jpg     # True positive — multiple cats
fp_human_and_cat_01.jpg     # False positive candidate — human + cat present
fp_empty_sofa_01.jpg        # False positive candidate — sofa with no animals
tn_human_only_01.jpg        # True negative — human only
```

Good free-to-use image sources:
- https://unsplash.com (search "cat garden furniture")
- https://pexels.com (search "cat outdoor sofa")
- https://pixabay.com (search "cat patio")
